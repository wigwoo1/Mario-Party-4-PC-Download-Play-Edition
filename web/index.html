Network optionsEnter a reachable STUN server (for example, stun:stun.l.google.com:19302) to help peers discover direct connection routes. STUN does not relay game traffic; some NAT and firewall combinations need a TURN relay. If using TURN, each player enters a reachable relay URL and their credentials on their own device. Credentials stay local and are not added to connection codes. This prototype does not provide a TURN relay, and Internet connectivity still needs testing on the relevant networks.
